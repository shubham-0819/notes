## 🛠️ Tech Stack

This documentation site is built using:

- [MkDocs](https://www.mkdocs.org/) - Static site generator
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) - Theme and framework
- [Python](https://www.python.org/) - Base requirement
- [uv](https://docs.astral.sh/uv/) - Python package/dependency manager
- GitHub Pages - Hosting

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python package manager)

### Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/shubham-0819/notes.git
   cd notes
   ```

2. Install dependencies:
   ```bash
   uv sync
   ```

3. Run locally:
   ```bash
   uv run mkdocs serve
   ```

4. Open in browser:
   ```
   http://127.0.0.1:8000
   ```
