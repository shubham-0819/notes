- [Python](https://www.python.org/) - Base requirement
- GitHub Pages - Hosting

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- poetry (Python package manager)

### Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/shubham-0819/notes.git
   cd notes
   ```

2. Install dependencies:
   ```bash
   poetry install
   ```

3. Run locally:
   ```bash
   poetry run mkdocs serve
   ```

4. Open in browser:
   ```
   http://127.0.0.1:8000
   ```
