## Common Patterns

| Pattern | When to Use |
|---------|------------|
| **Two Pointers** | Sorted arrays, palindromes, pair sums |
| **Sliding Window** | Subarray/substring of fixed or variable size |
| **Binary Search** | Sorted data, search space reduction |
| **BFS** | Shortest path in unweighted graph, level-order tree traversal |
| **DFS** | Path finding, cycle detection, connected components |
| **Dynamic Programming** | Overlapping subproblems, optimal substructure |
| **Backtracking** | Permutations, combinations, constraint satisfaction |
| **Divide & Conquer** | Merge sort, quick sort, binary search |
| **Greedy** | Interval scheduling, Huffman encoding |
| **Monotonic Stack** | Next greater/smaller element problems |

## Problem-Solving Template

1. **Understand** — Read the problem carefully, identify inputs/outputs
2. **Examples** — Walk through provided examples, try edge cases
3. **Brute Force** — Think of the naive solution first
4. **Optimize** — Identify bottlenecks, apply patterns
5. **Code** — Write clean code
6. **Test** — Run through examples, edge cases (empty, single element, large)
